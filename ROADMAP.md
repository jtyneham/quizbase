# Deferred Product Ideas

This file records agreed future ideas that are **not** active implementation
requirements. Do not add them opportunistically; revisit them only when the
user explicitly asks.

## Odd One Out: Knowledge Range

**Status:** Deferred.

Keep Odd One Out free of a topic picker. A possible future control is a
three-position, touch-friendly familiarity selector:

```text
Broad | General | Deep
```

It is not a difficulty control. Difficulty continues to describe how close or
subtle a relationship is; knowledge range describes how likely a casual group
is to recognise the terms. A future implementation should tag blueprints with
a separate familiarity level and select only eligible rounds for the chosen
range.

Do not implement this as a continuous slider: its three meanings are discrete.
Do not expose `Deep` until there is a substantial, varied, reviewed pool of
specialist material across several domains, so it does not become a
fandom-lopsided mode. Normal play must remain surprise-driven rather than
topic-driven.

## Odd One Out — Pokémon Edition

**Status:** Deferred concept.

Potential sibling game using Pokémon main-series game mechanics only: moves,
Abilities, items, types, species, evolutions, and battle terms. Exclude anime,
movies, NPCs, city names, and story/lore questions. Reuse the standard Odd One
Out engine and keep its dedicated Pokémon content in a separate reviewed data
file.

**Launcher icon concept:** retain the four-choice Odd One Out motif, but make
the circular lower-right choice slightly larger and render it as a simplified
Poké Ball. Do not create the asset or add the game until explicitly requested.
