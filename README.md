# Quizbase v2

A dependency-free, mobile/tablet-first collection of five quiz games built for deep visual reskinning.

## Run

Serve this repository with any static HTTP server and open `index.html`. ES modules do not run reliably from a `file://` URL.

## Test

```sh
npm test
```

The application has no runtime package dependencies. Tests use the Node.js standard library.
